# コタンの画像

ここに置いた画像が、見た目「コタン」のときにアプリへ表示されます。

| ファイル名 | いつ出るか |
| --- | --- |
| `normal.gif` | ふだん（今日の画面で吹き出しと一緒にいる） |
| `happy.gif` | 完了したとき（画面の下からひょこっと出てくる） |

- 拡張子は `gif` / `png` / `webp` / `apng` のどれでも大丈夫です（例：`normal.png`）。
- 背景が透明な画像（透過GIF・透過PNG）がおすすめです。
- `happy` がないときは `normal` を使います。どちらもないときは 🐯 が出ます。
- 表示の高さはおよそ 120〜140px です。縦長・正方形どちらでも、はみ出さないよう縮めて表示します。
- 1枚あたり数MBまでにしておくと、開くのが速くなります。
